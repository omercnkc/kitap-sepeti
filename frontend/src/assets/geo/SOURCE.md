# TR adres geo verisi

Kaynak: https://github.com/omercnkc/tr-il-ilce-mahalle-adress

T.C. İçişleri Bakanlığı NVİ Adres Kayıt Sistemi referanslı açık JSON veri seti
(`iller.json`, `ilceler.json`, `mahalleler-1.json` … `mahalleler-4.json`).

`mahalle-index.json` bu projede üretildi: `ilce_id` → ilgili `mahalleler-N`
parça numaraları (lazy yükleme için). Cadde/sokak bu veri setinde yok; yalnızca mahalle.
